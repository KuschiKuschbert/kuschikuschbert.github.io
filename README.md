## Rules
- Only public pages live here. App source code stays in the private app repos.
- The Rocktally privacy policy is also in the private Rocktally repo (`docs/launch/privacy-policy.html`) and inside the app. Change all three together and update the effective date. The app and Google Play link to the URL above, so never move or rename `rocktally/privacy/`.
- Plain HTML and CSS, no build step. `.nojekyll` turns off GitHub's Jekyll processing.
- No em dashes in page copy.
